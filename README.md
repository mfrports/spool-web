# spool-web

Spool's website, served by GitHub Pages at https://mfrports.github.io/spool-web/: the landing page
with the download, support and privacy. Spool itself is given out here, as the releases of this
repository (`releases/latest/download/Spool.dmg`), and `updates/` is the feed it updates from.

The pages are made in the app's repository (`Website/`) and copied here by `Scripts/publish-web.sh`;
the releases and the feed come from its `Scripts/release.sh`.
